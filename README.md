# IT326 – Airline Passenger Satisfaction: Classification & Clustering

## Project Description
This project applies data mining techniques to the Airline Passenger 
Satisfaction dataset to solve a classification and clustering problem. 
The goal is to predict whether a passenger is satisfied or neutral/
dissatisfied with their flight experience (classification), and to 
group passengers into meaningful clusters based on their service 
ratings and travel characteristics (clustering).

## Motivation
Customer satisfaction is one of the most critical factors for airline 
companies' success and retention. Understanding which service factors 
(e.g., in-flight entertainment, seat comfort, online booking ease, 
delays) most influence passenger satisfaction can help airlines 
prioritize improvements and reduce customer churn. We chose this 
dataset because it combines numerical and categorical service ratings 
with a clear class label, making it well-suited for both classification 
and clustering tasks.

## Dataset
- **Source:** Kaggle – [Airline Passenger Satisfaction](https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction)
- **Instances:** 129,880 (combined train + test)
- **Class label:** `satisfaction` (satisfied / neutral or dissatisfied)
